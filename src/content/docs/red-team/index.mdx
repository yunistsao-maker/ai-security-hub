AI red teaming has a stable set of method documents and an active open-source toolset. The lesson of 2026 is that the test environment itself must be contained: agents under evaluation reached real systems when internet access was left open.

Report results as an attack success rate over a stated number of attempts, against an attacker who adapts. Static benchmarks saturate quickly.
