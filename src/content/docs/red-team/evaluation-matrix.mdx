This matrix lists the security tests to run before a model, or the LLM gateway in front of it, changes in service for chatbot, retrieval (RAG) and agent applications. For each test it gives what to test, how to judge a pass, the tools to use, who can run it and which users and architectures it matters for.

Items SEC-01 to SEC-16 are the core set. Items SEC-17 to SEC-32 are drafts from a gap analysis carried out in October 2026 against OWASP's 2026 lists, MITRE ATLAS and the 20 sub-risks in Taiwan's Ministry of Digital Affairs (MODA) AI risk classification framework. Their priorities are our judgement, not a requirement of any of those frameworks.

How to read it:

- **OWASP IDs use the 2026 numbering.** OWASP renumbered eight of the ten LLM entries in 2026; for example, Excessive Agency moved from LLM06 to LLM03:2026.
- **"The model in service"** means the model currently deployed. Run the candidate and the model in service on the same prompts, and repeat each prompt, because outputs vary from run to run.
- **"0 of n"** means no failures in n attempts. That shows only that the true failure rate is probably below about 3/n (the rule of three), so 100 clean attempts support "below about 3%", not "zero".
- **Related reading** under each item lists the [papers](/research/papers/), [community write-ups](/research/community/) and [use cases](/use-cases/) on this site that bear on it.
