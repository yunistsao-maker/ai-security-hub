## 引用他人作品

- 每一頁都以我們自己的話撰寫，並連結到來源。
- 簡短引文會標註出處。
- 框架編號與清單標題（例如 LLM01:2026 Prompt Injection）作為引用使用並標註來源。OWASP 的 LLM 十大風險以 CC BY-SA 4.0 授權發布。
- 不複製 ISO 標準內容，也不複製採非商業授權的來源。
- 新聞只收錄標題與連結，不儲存文章內容。
