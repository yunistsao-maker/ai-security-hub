AI security references change monthly, so every fact here carries the evidence behind it.

- **A source on everything.** Every page and every table entry links to the page it was read from. The build fails if an entry has no source or no check date.
- **A check date on everything.** Each page shows when it was last checked. Entries older than 90 days are flagged for review.
- **Primary sources first.** Regulators, standards bodies, vendors' own advisories and original research. Where only a law-firm or press summary was available, the entry is marked as a secondary source.
- **Attribution is worded carefully.** When an incident is attributed to a named organisation, the entry says who made the attribution, unless that organisation confirmed it.
- **Fixed status words.** In force, applies from a date, draft, guidance or voluntary. Never "new" or "upcoming".
- **No working attacks.** Attacks are described conceptually. The site publishes no working exploit strings or jailbreak payloads.
- **Our own words.** Pages summarise and link. See [sources and licences](/about/licences/).
